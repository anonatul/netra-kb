## 2026-08-17 — SIH Judge Simulation (67/100)

### What happened

A judge-style technical evaluation panel reviewed the NETRA proposal.

**Verdict:** promising orchestration layer, not yet finalist-level. Score **67/100** (screening 78, finalist 68, winning 55).

**Key findings:**

1. ERSS-112 already accepts SMS + multi-channel and uses GIS dispatch → "NETRA replaces 112" / "existing systems rely on humans" positioning is not differentiation.
2. SACHET is more capable than "one-way SMS" characterization; Cell Broadcast is now national.
3. "2G survives when 4G/5G fails" is not a reliable disaster assumption.
4. Femtocell/drone "phones auto-connect" claim is an architecture fantasy without a telecom partner.
5. AML/ELS already exists (UP operationalized Dec 2025) → integration dependency, not innovation.
6. AI for keyword classification doesn't justify AI; rules are better.
7. Fixed 50m DBSCAN is arbitrary; adaptive clustering needed.
8. "No ping = rescued" is invalid; silence ≠ safety.
9. Automatic supply lists need explainable reasoning + dispatcher confirmation.
10. Security/privacy underdeveloped (phone numbers, locations, medical data).
11. Architecture overcomplicated (Kafka+RabbitMQ duality unnecessary).
12. Rescue Priority Score = the defensible core innovation.

### Decisions made

- ✅ Reposition NETRA as **intelligence layer over ERSS/SACHET**, never a replacement (files 00, 03, 04, 18).
- ✅ Delete full-blackout/femtocell claim from core MVP; Tier 3 only as controlled experiment (files 16, 17, 26).
- ✅ Make **Rescue Priority Score** the central innovation; add independent evidence count, incident confidence, adaptive clustering, freshness (files 04, 06, 10, 15, 24).
- ✅ Three-layer AI: rules → lightweight multilingual classifier → optional LLM off critical path (file 12).
- ✅ One queue mechanism; modular monolith; PostgreSQL/PostGIS; local-first demo (files 09, 16, 24).
- ✅ Connectivity state machine NORMAL→DEGRADED→SEVERELY DEGRADED→CELLULAR UNAVAILABLE (files 14, 24).
- ✅ Security & privacy action plan (file 13).
- ✅ Benchmark vs manual baseline with defined metrics (files 19, 20).
- ✅ Killer demo scenario: 0 → 50 reports → 17 incidents → 6 zones → P1 escalation → RESCUED (file 21).
- ✅ Revised pitch (file 23), Q&A script (file 22), research plan (file 27).
