## 1. The Benchmark That Makes or Breaks the Project

> **NETRA vs manual/human triage on the same dataset, measured on defined metrics.**

### Dataset (synthetic)

10,000 simulated disaster reports:

- Hindi, English, Hinglish, Marathi, Bengali, Tamil
- noisy SMS
- duplicates
- false reports / fake SOS bursts
- safe messages
- urgent medical cases
- stale reports
- inaccurate locations
- varying severity / vulnerability

With labelled ground truth.

### Baselines

- A: raw report count / naive map
- B: simple severity rules only
- C: human/manual prioritization

### Metrics

```text
Triage time              manual: 8 min  → NETRA target: ~22 s
Precision / Recall / F1  priority and classification
Duplicate reduction      1,000 reports → unique incident clusters
Top-zone accuracy        % of top-10 NETRA zones confirmed genuinely high-risk
False-critical rate      % incorrectly marked P1
Location error           estimated vs ground truth
NLP extraction F1        severity / vulnerability / victim count
Recommendation acceptance  % accepted by trained responders
```

## 2. Key Hypotheses to Test

| # | Hypothesis | Test |
| - | ---------- | ---- |
| H1 | Incident consolidation reduces operator workload | Reports inspected before identifying top priorities: manual vs NETRA |
| H2 | Priority model beats report-count ranking | Labelled scenarios, expert evaluation |
| H3 | Multilingual extraction reduces interpretation time | EN/HI/Hinglish labelled set, precision/recall/F1 |
| H4 | Confidence-aware clustering beats raw pins | Zone accuracy vs ground truth |
| H5 | Priority queue reduces cognitive load | Operator task-completion experiment |

## 3. Adversarial Testing (Judge-Impressive)

Inject adversarial cases and show NETRA behaves correctly:

- 500 fake SOS from one location → confidence REDUCED, pattern flagged (not "MASSIVE CRISIS")
- 30 duplicates from one device → counted as ONE source, not 30 victims
- GPS errors → confidence radius shown
- stale signals → freshness decay, never "safe"
- AI misclassification → rule fallback + human review queue
- sudden report burst (100 → 5,000/min) → queued, no silent loss
- network disconnection → local mode continues
- dashboard restart → state recovered

## 4. Validation Evidence Plan

Minimum target:

- 2–3 disaster-response/control-room workflow discussions
- 2–3 responder interviews
- 1 emergency-management expert review
- official emergency-response documentation (SOPs, RFPs)
- controlled simulation benchmark
- labelled multilingual dataset evaluation

Label secondary evidence as secondary.
