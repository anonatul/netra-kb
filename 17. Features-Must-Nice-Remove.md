## 1. 🟢 MUST HAVE (MVP Core)

### Incident intelligence

- multi-source incident fusion (SMS + 112 + ELS + field + manual)
- incident normalization
- duplicate / related-evidence detection
- **independent-source count** (messages ≠ victims)
- multilingual incident extraction (EN/HI/Hinglish)
- location processing with confidence radius
- adaptive clustering (uncertainty-aware)
- incident confidence score

### Decision engine

- **Rescue Priority Score** (the heart of NETRA)
- severity + vulnerability + recency + confidence + accessibility factors
- explainable priority (reasons + evidence + version)
- explainable resource recommendation (rule-based first)
- human override with audit

### Operational interface

- priority queue (P1/P2/P3/P4)
- map with zones + confidence
- incident details + evidence + timeline
- field verification / status updates
- filters (priority, status, geography, confidence, freshness)

### Reliability & safety

- offline command-center mode
- graceful AI / location / priority fallback
- never equate silence with safety
- no autonomous life-critical actions
- audit trail + RBAC + authentication
- deterministic demo scenario + scenario replay

## 2. 🟡 NICE TO HAVE

- additional languages (Marathi, Bengali, Tamil…)
- LLM layer for difficult unstructured reports (off critical path)
- alerting (rate-limited, P1 changes, bursts)
- connectivity state machine visibility (NORMAL→DEGRADED→CELLULAR UNAVAILABLE)
- HDBSCAN / graph clustering if benchmarks justify
- advanced anomaly detection
- IoT / sensor integration
- satellite / alternative-communication integration (separate layer, experimental)
- predictive analytics (long-term)

## 3. 🔴 REMOVE FROM MVP (Judge-Validated)

- **"phones automatically connect to our drone femtocell"** — unsupported claim
- **"2G always survives disasters"** — false claim; towers can die entirely
- **"no new ping = rescued"** — wrong inference
- **"Google Maps fails completely without 4G/5G"** — simplistic
- **"NETRA works with zero cellular infrastructure"** — not true without a separate validated layer
- Kafka + RabbitMQ duality — pick one mechanism
- AI for simple keyword classification — use deterministic rules
- blockchain
- autonomous dispatch
- custom nationwide telecom network
- LLM in the emergency critical path

## 4. Golden Feature Rule

> **If a feature does not improve the quality, speed, confidence or usability of a rescue decision, it is not part of NETRA's core MVP.**
