## 1. MVP Mission

> **Prove that NETRA converts noisy, multilingual, high-volume emergency reports into useful, explainable rescue priorities faster and better than manual triage.**

## 2. MVP Technology (Judge-Recommended)

```text
FastAPI + PostgreSQL/PostGIS + Redis + lightweight NLP + React
```

- modular monolith (no microservices)
- one queue mechanism only (no Kafka + RabbitMQ duality)
- local-first: demo runs fully offline on one machine

## 3. MVP Must Demonstrate

- simulated multi-source ingestion (SMS / 112-style / ELS / field / manual)
- incident normalization
- duplicate / related-evidence detection
- multilingual incident extraction (EN + HI + Hinglish minimum)
- location processing + confidence radius
- adaptive spatial clustering (uncertainty-aware, not fixed 50m)
- **Rescue Priority Score** (severity × vulnerability × recency × confidence × access)
- P1/P2/P3/P4 priority queue
- explainable resource recommendation
- incident lifecycle + field verification
- offline command-center mode
- audit trail + RBAC
- deterministic scenario replay for demo

## 4. MVP Does NOT Include

- real ERSS / SACHET / ELS / telecom integration (use simulation adapters)
- femtocell / drone / portable-network claims
- full-blackout communication
- autonomous dispatch
- LLM in the emergency critical path (optional Layer 3 only)
- Kafka / RabbitMQ / Kubernetes
- nationwide deployment
- 12-language support (EN/HI/Hinglish first)

## 5. MVP Architecture Sketch

```text
SMS / 112 / ELS / simulated reports
             ↓
      Ingestion Gateway
             ↓
       Incident Queue
             ↓
     Triage + Extraction
             ↓
       PostgreSQL/PostGIS
             ↓
    Priority/Clustering Engine
             ↓
       Responder Dashboard
             ↓
      Resource Recommendation
```

## 6. MVP Acceptance

- benchmark vs manual baseline measured (see file 19)
- deterministic demo scenario (see file 21)
- offline operation demonstrated
- AI failure fallback demonstrated
- fake-report burst detected (confidence reduced, flagged)

## 7. Golden MVP Rule

> **Solve ONE battlefield exceptionally: "When thousands of emergency signals arrive during a disaster, how do responders determine which locations need attention first?"**
